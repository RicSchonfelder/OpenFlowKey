# OpenFlowKey

OpenFlowKey é um aplicativo gratuito e de código aberto para compartilhamento de teclado e mouse. Use o teclado, mouse ou trackpad de um computador para controlar computadores próximos e trabalhe de forma contínua entre eles.

[Página inicial](https://openflowkey.org) [Código](https://github.com/openflowkey/openflowkey)
