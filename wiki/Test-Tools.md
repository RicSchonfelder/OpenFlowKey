# Visualizador de Eventos de Teclado

https://w3c.github.io/uievents/tools/key-event-viewer.html

Mostra os códigos reais das teclas, executa no navegador. Útil para testar quais teclas os clientes estão emulando.

# Visualizador de Eventos de Mouse

https://domeventviewer.com/mouse-event-viewer.html

Mostra eventos de mouse no navegador. Útil para testar pressionamentos de mouse nos clientes.
